How does Task Set #7 stay the same set, but give two students different papers?

You said: dynamic, leak-proof, "same question type, different version, different options". Here are the three ways to build that. Pick one — or tell me a mix.

A

Concept-slot set — #7 is a frozen list of 45 concepts

TASK SET #7 = [ yield-at-roundabout, stopping-distance-wet, sign-362, … ]  (45 concept slots, fixed forever)
Student A slot 1 → "You approach a roundabout…" options shuffled
Student B slot 1 → "Who has right of way here?" options shuffled
Coverage: guaranteed — finish all sets, you've met every concept.
Leak resistance: depends entirely on how many alternates exist per concept. With 1 variant per concept (today's reality) both students get the identical question, only the option order differs.
B

Shape-only set — #7 is just a blueprint, drawn fresh every sitting

TASK SET #7 = { 8 signs, 7 yield, 6 vehicle, … · difficulty 30/40/30 }  (a shape, no fixed questions)
Student A → 45 drawn from the whole bank matching that shape
Student B → 45 different ones from the whole bank
Leak resistance: highest — nothing to leak, the paper never repeats.
Coverage: none — a student can grind 32 sets and never see some questions.
Set identity: meaningless — #7 and #12 differ only by random seed. The grid becomes decorative.
C

Pool-slice set — #7 owns a slice of the bank, each sitting draws from that slice

BANK (approved, mixed TEXT + IMAGE + SIGN) — AI partitions it into balanced slices
#6 · 70 concepts #7 · 70 concepts ← the set's identity #8 · 70 concepts
Student A sits #7 → engine draws 45 of those 70, seeded per user+attempt
Student B sits #7 → a different 45 of the 70, different phrasings where alternates exist
Student A retries #7 → different 45 again. Never the same paper twice.
Coverage: guaranteed — every question lives in exactly one slice.
Leak resistance: strong even with today's single-variant bank — you can't memorise "set 7 = these 45", because it's 45-of-70, reshuffled, re-optioned.
Set identity: real — #7 is a genuine, stable chunk of material. "Passed #7" means something.
Gets better automatically as AI alternates land, without changing the model.
